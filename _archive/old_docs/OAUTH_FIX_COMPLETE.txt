✅ CORRECT AUTHENTICATION FLOW:

1. Client uses Google Sign-In SDK (Flutter/Android/iOS)
   ↓
2. Client gets Google ID token from SDK
   ↓
3. Client sends ID token to backend:
   
   POST https://games.agames.cv/api/users/auth/google/
   Body: {"id_token": "google_id_token_here"}
   ↓
4. Backend verifies token with Google
   ↓
5. Backend returns API token:
   {
     "token": "abc123...",
     "user": {...},
     "is_new_user": true/false
   }
   ↓
6. Client saves the token and uses it for all API calls:
   Authorization: Token abc123...

API Endpoint:
  https://games.agames.cv/api/users/auth/google/

Google Client ID (for mobile SDK):
  your-client-id.apps.googleusercontent.com

Request Format:
  POST /api/users/auth/google/
  Content-Type: application/json
  Body: {"id_token": "YOUR_GOOGLE_ID_TOKEN"}

Response:
  {
    "message": "Login successful",
    "user": {
      "id": 123,
      "email": "user@example.com",
      "username": "user",
      "is_email_verified": true,
      "is_premium": false
    },
    "token": "api_token_here",
    "is_new_user": false
  }

Using the Token:
  All subsequent API calls should include:
  Authorization: Token <the_token_from_response>

Example API Call:
  GET https://games.agames.cv/api/games/
  Headers:
    Authorization: Token abc123xyz...
