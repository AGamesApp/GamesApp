├──────────────────────────────────────────────────────────────────┤
│ EXPLAINED: System uses Firebase Cloud Messaging (FCM)            │
│                                                                   │
│ How it works:                                                    │
│                                                                   │
│  1. User downloads app                                           │
│     ↓                                                            │
│  2. Firebase creates device token automatically                  │
│     ↓                                                            │
│  3. App sends token to backend                                   │
│     ↓                                                            │
│  4. Backend stores token (no account needed)                     │
│     ↓                                                            │
│  5. Admin sends notification                                     │
│     ↓                                                            │
│  6. Firebase delivers to ALL devices                             │
│                                                                   │
│ Result:                                                          │
│   • Anonymous users → Get push notification ✓                    │
│   • Registered users → Get push + database copy ✓                │
│                                                                   │
│ No account needed to receive notifications!                      │

The notification system works like a radio broadcast:

📻 Radio Tower (Your Backend)
   ↓
📡 Broadcast Signal (Push Notification)
   ↓
📱📱📱 All Radios Receive (All Devices)
   │
   ├─ Anonymous user → Hears broadcast ✓
   ├─ Anonymous user → Hears broadcast ✓
   ├─ Registered user → Hears broadcast + Gets recording ✓
   └─ Registered user → Hears broadcast + Gets recording ✓

You DON'T need a subscription (account) to hear the broadcast!
You ONLY need a subscription for the recording (database copy)!
