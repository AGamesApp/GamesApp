🗑️ DELETE SUPPORT MESSAGES:
────────────────────────────
1. Go to: https://games.agames.cv/customadmin/support/
2. Single delete: Click 🗑️ button next to message → Confirm
3. Bulk delete: Click "🗑️ Delete All" button → Confirm
4. Filter works: Delete all pending/reviewed based on active filter

🖼️ ADD GAME IMAGES:
────────────────────
1. Edit game in dashboard
2. In "Game Images & Screenshots" section:
   - Choose ONE: Paste URL OR upload file
   - Cannot do both (validation prevents it)
3. Save game

📊 IMPORT GAMES:
────────────────
1. Prepare Excel (last row = newest game)
2. Run: python import_games.py
3. Paste Google Sheets link
4. Games imported automatically in reverse order
